# Number Guessing Game 🔢❓

A simple Python game where the user attempts to guess a randomly generated number between 1 and 100.

## 🎮 How it Works
1. The computer generates a random number between **1 and 100**.
2. You enter your guess via the terminal.
3. The program provides hints ("Higher" or "Lower") to guide you to the correct number.
4. Once you guess correctly, the game reveals the total number of attempts it took.

## 🚀 How to Run

1. Ensure you have Python installed.
2. Run the script using the command:
   ```bash
   python main.py
